# Sabotage-target audit (P3-01)

The harness proves each entry's target goes red under its patch. Until P3-01 nothing proved *why*.
This table records, for every entry, the behaviour its patch breaks (`mechanism:`), its target,
the verdict, and the failure message its target produced in the discovery run (every entry run
once, on the commit before P3-01's, with messages printed).

Verdicts:

- **reasoned**: the entry states a `reason:`. The harness requires the target's failure message to
  contain it, or reports `wrong-reason`. Required for every target on `ci/broad-targets.txt`; used
  elsewhere where the message names the mechanism (an allowlist entry names the type it caught).
- **direct**: a narrow target, whose failure message in the discovery run was its own assertion
  about the mechanism. This judgement is not scripted; the message is the evidence.
- **retargeted / repaired**: the entry or its test changed because the discovery run showed a red
  for another reason. Listed in full below.
- **command / host command**: the check is a command that must exit non-zero with a stated
  message; the message already says why.
- **harness control**: the harness's own controls (S-meta, S-audit).

Counts: command 24, direct 64, harness control 5, reasoned 21, repaired 3, retargeted 3 (of 120).

## What the audit found

- **Two entries were caught for the wrong reason.** S-cov-5 and S-cov-6 turned their targets red
  through a `KeyNotFoundException`, one in the shared coverage measurement and one in the patch's
  own untouched branch. Neither reached the assertion its entry claimed to test. Both patches are
  repaired and now state the rule or row that must fail.
- **One target failed by throwing.** S-shrink-4's target threw from a `First()` in its seed search.
  The throw was caused by the mechanism (the signature lost its key), but an exception proves less
  than an assertion; the test now asserts, with a message.
- **Two entries aimed at golden values** (S-det-3, S-rng-1), which any change turns red. Both now
  aim at a test of exactly their mechanism.
- **Every other red was an assertion about the mechanism.** 23 entries aim at broad targets
  (two of them the harness's own controls); each states a reason, confirmed in the run that follows.
