# Every input a gate reads, and what verifies it (P13-01, `gates inputs`). Phase 12's class finding:
# a gate reading a file kept by hand reads it as true, so it cannot be the check that the file is
# current. One line per input, PATH KIND DETAIL, KIND one of
#   currency OBSERVER   a claim about something observable, compared with it on every run of the
#                       observer (tools/Raft.Gates/Currency.cs: one comparison, one failure text)
#   construction GATE   compared with what it describes, both ways, by that gate on every run
#   subject REASON      what a gate checks, not a premise
#   decision REASON     a chosen value with nothing to observe; a change to it is visible in review
#   row "TEXT" REASON   a premise nothing checks yet; TEXT is in exactly one open register row
# `gates inputs` finds the inputs in the tree (every file under ci/, every ci/ path a script, test,
# project file or workflow names, every repository path a string literal in the gates' source
# begins with) and fails one with no line here: a gate reading a new file fails until someone says
# what verifies it, and "nothing yet" is a register row.

ci/inputs.txt                   subject       this registry, compared by gates inputs with the inputs it finds

# The four phase 12 found checked by nothing (P12-01's audit), each with an observer where its truth lives;
# and the first premise this registry's first application found (P13-01), given an observer by P14-05.
measurements                    currency      record-commit: each record's commit among the head's ancestors (gates measurements)
ci/sabotage-touched.txt         currency      touched-run: the touched stage's run within a factor of 3.25 of its estimate (gates sabotage --touched)
ci/sabotage-costs.txt           currency      github-run: the run's total within a factor of 2 of the file's sum (build-collect); each entry within 5 and each shard within 3 in the harness
ci/budget-seeds.txt             currency      soak-ranking: each seed among the baseline soak's ten hardest decided histories (the soak job)
ci/broad-targets.txt            currency      broad-run: every test red beside at least half of the entries that ran it beside their target, and at least four, listed (build-collect, P14-05)
