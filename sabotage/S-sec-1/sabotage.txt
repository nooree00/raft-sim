description: A freshly generated GitHub-token-shaped secret, committed in a scratch clone, must be found (never a well-known example key, which scanners allowlist)
mechanism: the secret scan misses a committed token
kind: command
runner: host
build: no
baseline: d=$(mktemp -d) && git clone -q "file://$PWD" "$d" && scripts/secret-scan.sh "$d"
command: d=$(mktemp -d) && git clone -q "file://$PWD" "$d" && tok="ghp_$(tr -dc A-Za-z0-9 </dev/urandom | head -c 36)" && echo "token = \"$tok\"" > "$d/leak.txt" && git -C "$d" add leak.txt && git -C "$d" -c user.name=s -c user.email=s@example.com commit -qm leak && scripts/secret-scan.sh "$d"
expect: caught
message: secret-scan: leaks found
